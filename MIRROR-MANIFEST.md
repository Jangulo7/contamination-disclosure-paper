# What goes into the anonymised mirror

Read this before running `ANON-MIRROR-REGISTRATION.md`. It answers one question:
*which files does a reviewer get, and which must never reach them?*

Last verified 2026-08-17.

## The mirror already exists — add to it, do not rebuild it

**Do not point 4open.science at `contamination-disclosure-paper`.** This
repository's git history contains the full manuscript and the author block — its
own `.gitignore` says so:

> *"untracking removes these from the index going forward. It does NOT remove
> them from the existing history — earlier commits still contain the full

An anonymised view is a view over a repository, and a repository whose history
carries your name is one misconfiguration away from showing it.

instrument" would itself tell a reader the mirror was assembled for review, and

## What must NOT reach the mirror

| Excluded | Why |
|---|---|
| `main.tex`, `references.bib`, `main.bbl`, `checklist.tex` | reviewers get the PDF through OpenReview; the source carries the author block and the named self-citations |
| this repository's root `README.md` | it is author-facing: build instructions, the anonymity toggle, the open-items list. It also tells a reader that a separate public specification repository exists |
| `MIRROR-MANIFEST.md` (this file) | describes the anonymisation, which is itself a signal |
| `.anon-patterns` | a list of the strings that identify you — the single worst file to publish |
| `check-anonymity.sh`, `.anon-patterns.example` | harmless, but they advertise that anonymisation was performed |
| `.gitignore` | its comments describe the manuscript workflow and the history problem |
| `neurips_2026.sty` | build dependency, not an artifact |
| `.private/` | the working area: superseded drafts, edit-round changelogs, retired assets |

4open.science serves the **root** README as the landing page. In the mirror that
is the specification's README, which is correct and already scrubbed — so
`audit/README.md` sits one level down and needs a link from the root README to be
found at all. `ANON-MIRROR-REGISTRATION.md` step 1 has the paragraph to paste.

What must never become that landing page is *this* repository's root README: it
is author-facing, and it tells a reader that a separate public specification
repository exists.

## Before you register

```bash
./check-anonymity.sh                    # must exit 0
./check-anonymity.sh path/to/main.pdf   # must exit 0
python3 audit/score.py --selftest       # must pass
```

Install `poppler-utils` first, or the PDF text-layer check degrades to a
`strings(1)` scan that misses compressed streams.

Then the logged-out checks in `ANON-MIRROR-REGISTRATION.md` step 4, which now
cover the audit files as well as the specification. Do those in a private window:
logged in, you see a different result than a reviewer does.

## Naming

The mirror repository must **not** be named `contamination-disclosure` or
`contamination-disclosure-paper`. 4open.science builds its public URL from the
repository name, so a matching slug identifies you in one search.
`eval-reporting-artifact` is neutral and is the name already written into the
paper's Availability section.
